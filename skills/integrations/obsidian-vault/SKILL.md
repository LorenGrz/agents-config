# Obsidian Vault

## Objective

Read, write, search and organize notes in the Obsidian vault following its layout and conventions; delete or move only with approval.

## Prerequisites

### Location

Vault path: `$OBSIDIAN_VAULT`, default `~/Documents/Obsidian Vault`.

### Layout

- `projects/<slug>/` (slug lowercase, hyphens) with:
  - `<slug>.md`: index note
  - `plan.md`
  - `fuentes/`: one note per source
  - `notas/`: Q&A and working notes
- `agents-config/`: generated docs of the agents-config hub. Do not hand-edit; they are regenerated by `scripts/export-obsidian.sh`.

## Rules

- In a repo that matches an organization, use that organization's replacement skill when one is installed (e.g. in `.claude/skills/`); its rules win.

### Note conventions

- Frontmatter: `title`, `tags`, `created`, `status`.
- Link with wikilinks `[[note-name]]`; link index notes to children and back.
- Check `list_directory` and `search_notes` before creating, to avoid duplicates.

### Tools (obsidian MCP)

- `read_note`, `search_notes`, `list_directory`: free to use.
- `write_note`: create or replace a note.
- `patch_note`: small edits; prefer it over rewriting a whole note.
- `update_frontmatter`, `manage_tags`: metadata changes.

### claude-obsidian plugin

For LLM-wiki style ingestion and querying, use its skills: `/claude-obsidian:wiki`, wiki-ingest, wiki-query.

### Safety

- Delete or move notes only with the user's OK, listing exactly what changes.
- Commit or back up the vault before bulk edits.
- Never write secrets into notes.
- For NotebookLM sync, use the `notebooklm-obsidian-sync` skill.
