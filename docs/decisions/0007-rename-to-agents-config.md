# 0007 — Renombrar agent-config a agents-config

Estado: aceptado (2026-10-23).

## Contexto

El proyecto se llamaba `agent-config` pero instala en el directorio local `~/.agents/`. El singular no
coincidía y costaba relacionar el repo, el plugin y las rutas.

## Decisión

- Todo pasa de `agent-config` a `agents-config`: el repo de GitHub (`LorenGrz/agent-config` ->
  `LorenGrz/agents-config`; GitHub redirige las URLs viejas), los nombres del plugin y del marketplace, la
  documentación y la skill de setup (`meta/agent-config-setup` -> `meta/agents-config-setup`).
- El identificador del plugin cambia de `agent-config@agent-config` a `agents-config@agents-config`.
- `install.sh` sigue siendo compatible: migra `~/.config/agent-config` a `~/.config/agents-config`, acepta el
  marcador viejo `generated by agent-config install.sh` (los archivos generados viejos se regeneran, no se
  respaldan), y sigue leyendo `AGENT_CONFIG_STATE_DIR` y exportando `AGENT_CONFIG_HOME` junto a los nombres
  nuevos.
- `meta/roadmap-coach/scripts/update-stage.sh` cae a la ruta vieja del perfil.

## Consecuencias

- Quien instaló el plugin con el nombre viejo tiene que reinstalarlo; las instalaciones con `install.sh` se
  actualizan solas. Los nombres viejos quedan en el código de compatibilidad hasta una limpieza.
